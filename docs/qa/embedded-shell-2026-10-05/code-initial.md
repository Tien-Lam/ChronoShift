## Architecture recommendation and review criteria

Build-owned canonical HTML embedded as serialized `SHELL` in generated worker removes reliance on mutable/transformed HTML network responses without accepting arbitrary transformed bytes. Include final CSP-injected UTF8 HTML, same release identity/integrity, exact SHA256 check before staging and normal text/html Content-Type. Own intact cache still reusable. Missing/corrupt index can regenerate locally from same worker release, including older controller after tree replacement. Keep all otherasset mismatch rejection and fetch bounds. Failedstaging must not overwrite intact cache; updates remain explicit, waiting update independent of readiness failure, and old tabs retain lazyworker assets.

Potential gaps to challenge: build placeholder escaping/substitution, final HTML vs source HTML, cache stats honesty for generated vs downloaded document, source-tree retirement fixtures, existing tests that previously corrupted index as generic asset failure, canonical response integrity mismatch rejection, ROOT/Pages bases, navigation/offline reopen after repair, old-controller waitingupdate draft behavior. The source-shell itself is trusted to same extent as delivered workerJS; if an intermediary modifies workerJS too, this fix is not a general network-integrity guarantee.

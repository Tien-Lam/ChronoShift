## Independent derivation and finding

Before reading new regression expectations, traced App worker request ownership, copy request ownership, reset/date validity and prefs effects; traced controlled ComboBox input/selected value through installed React Aria and Stately sources. Derived paths: exact option selection versus custom blur; stale async clipboard/worker completion after an edit; partial date keeping a prior committed value; reset remount and clear-calendar recovery; menu opening a deeply placed selected option while the page can scroll; same-event callback batching of preferences. Inspected surrounding unchanged conversion, format, preferences, update and build/precache owners.

**P1: selected timezone opening can scroll the page and immediately dismiss the popup.** Fresh context → open Appearance → enter/commit `Pacific/Chatham` → open More options → click Show target timezones. At 280×844, 390×844 and 1280×844, both typed exact selection (followed by Tab) and list selection reproduce on the initial runtime and the Group delta. DOM events show `aria-expanded=true`, then popover and root/window scrolling (page scrollY 188 at 280/390, 216 at 1280), input refocus and `aria-expanded=false`; no popup remains at 300ms. This prevents browsing/changing a committed zone through its arrow. See `narrow.json` and captures in the evidence directory.

The initial wrapper/triggerRef containment hypothesis is insufficient. Installed ComboBox uses Group when available but its selected-item auto-focus still runs `scrollIntoView(listbox, selectedElement)` followed by `scrollIntoViewport`. `useCloseOnScroll` closes on scrolling a trigger ancestor including the document/window. CSS supplies `.choice-list { max-height: min(320px, var(--available-height)); overflow:auto }`, but Popover does not provide that custom property. This makes the list height limit invalid and permits scroll ownership to fall to its outer popover. A separate CSSOM read before opening masked the symptom in one exploratory probe, so timing and layout identity matter; that exploratory probe is not claimed as acceptance.

Root proposed capturing the initiating activeElement and rechecking it with copyId in the deferred frame. Request identity is necessary but alone does not represent focus ownership. Element identity is also insufficient if focus leaves and returns to that element before the callback. A focus generation would distinguish that sequence.

The WebKit/Safari pointer case must be measured: if clicking Copy leaves the previous target input focused, the initiating activeElement can already be the target. A subsequent pointer or keyboard interaction with that same element need not change activeElement or fire another focus transition. An identity-only guard can then allow the old callback to steal focus despite newer interaction. A focus-generation-only guard can miss the same-element case. Conversely, requiring the copy button to be active could break automatic manual-copy selection in a browser that does not focus it on pointer activation. These are competing browser conditions, not observations from the missing historical trace.

The bounded old-source control should record the actual initiating activeElement and capture focus/blur plus pointer/key event order without storing user input text. Candidate policy should snapshot ownership after the initiating copy event and yield to a later interaction or focus generation, while still automatically selecting the fallback for an undisturbed request. Internal programmatic transitions need a stated policy; checking identities alone is not proof of user intent.

Candidate acceptance cases: ordinary immediate clipboard rejection still selects usable fallback; focus moves to a different visible control without changing its value; focus leaves and returns before the pending frame; same-element newer interaction where the Copy activation did not focus the button; input invalidates a request; a newer copy supersedes an older rejection/frame; and conversion/source correction keeps its existing semantics. All retain normal motion and visible keyboard/option interactions. The retained first-failure gap remains even if a scheduling-controlled equivalent race is proved.

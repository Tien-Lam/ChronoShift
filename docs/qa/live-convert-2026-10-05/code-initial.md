7. Empty/whitespace draft clears immediately; >10,000 input produces actionable feedback without worker creation and recovers after shortening. Rapid draft/settings changes should coalesce rather than launch every keystroke.
8. Restored update draft/share/clipboard/example/replace actions must all schedule automatically. Update activation remains explicit; no input content is persisted permanently or sent to network.
9. Engine semantics/result hierarchy remain unchanged. Independently expected instants must still distinguish source-zone, target-zone, reference-date, numeric-date-order and format changes.
